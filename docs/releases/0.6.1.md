# Release v0.6.1

- [Release v0.6.1](#release-v061)

Allow new package links on exact stable Gitea `28.2.0` alongside existing stable `1.25.x` support, based on reviewed upstream source. Other `28.x` versions, development builds, suffixes, and malformed version responses remain unsupported for link writes. Correct existing links remain read-only without a version check.

Preserve strict identity checks, refusal to replace visible or permission-hidden links, operator-enforced exclusion of other association writers, and one POST followed by exact read-back. Existing-link refusal is not an atomic compare-and-set. Local regressions cover both supported contracts; no live publication, package API, account permission, or Packages-tab rendering is certified.

See [package association](../bash-publication.md#package-association) for pinned source evidence and downstream compatibility review. Existing promotion and config-local Buildx-plugin warnings remain unresolved. Changed release scripts cannot adopt publications bound to older script identities; use the preserved original checkout/pin for those retries.
