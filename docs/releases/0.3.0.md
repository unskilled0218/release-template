## Changes

Build and publish a single two-platform image with `./scripts/release.sh`, a root Dockerfile, and a small explicit settings file. A standard-library data helper removes the jq dependency. Publication verifies immutable images, annotated tags, and project-focused notes without automatic cleanup.

## Compatibility

The default command and identity format change. The Python checkpoint workflow remains available through its original pinned checkout and an explicit legacy entry point. No checkpoint migration, package reassignment, or deletion is authorized. Verification for this release is local only.
