# Release v0.5.0

- [Release v0.5.0](#release-v050)

Link the published container package to the configured Gitea repository so it can appear in the repository's Packages tab. Verify exact package and repository identities, preserve correct associations, and refuse observed conflicting links instead of reassigning them.

Completed-publication retries can finish an unlinked package association without rebuilding or republishing the image, tag, or release. Verify accepted links through fresh API reads, including reconciliation of lost transport responses without repeating the link POST in the same invocation. Association failures preserve published objects and report incomplete or uncertain outcomes.

Association applies to every version of the configured package and requires operator-enforced exclusion of other association writers through request completion. New link writes require stable Gitea 1.25.x, whose server-side link operation rejects an already-linked package, including a link hidden by repository permissions. Existing correct links need no write or version check. This release has local verification only; existing promotion and config-local Buildx-plugin warnings remain unresolved.
