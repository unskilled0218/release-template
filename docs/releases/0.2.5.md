## Fixes

Local finalization now distinguishes a multi-platform store's reference identity from its per-platform identities. Default-build staging references receive write-ahead ownership records and can be untagged before the same run's immutable references are removed. Unrelated, pre-existing, uncertain, and container-used content remains protected. Restart tests cover interruption between those exact-reference operations.

## Compatibility

This follows the verified v0.2.4 publication without rewriting its source, tag, release description, or checkpoint. Resume existing transactions with their original pin and ownership records. Local ownership uses a new nested record version; outer checkpoint and retirement schemas remain unchanged. Remote cleanup still requires separate approval and deployment-specific evidence.
