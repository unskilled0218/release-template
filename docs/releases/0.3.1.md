## Fixes

Failed prerequisite registry reads now stop publication before promotion, and a newly foreign latest alias cannot become overwrite permission. Once the exact release tag is confirmed, its disappearance or replacement blocks later publication writes. Private authentication setup preserves the caller's Docker host/context/TLS and builder selection instead of introducing a default-context override.

## Compatibility

The single-command interface, identity/configuration formats, original-pin refusal, resource budgets, and conservative startup retries remain unchanged. No automatic repair, rollback, package reassignment, or deletion is introduced. Verification is local only; no live publication or daemon-routing attestation is claimed.
