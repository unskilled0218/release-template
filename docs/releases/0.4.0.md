## Changes

Support only the single-command Bash release workflow. Remove the old Python release engine, examples, managed installer/updater, legacy CLI, and their unsupported tests and active guides. Keep useful current-workflow tests and the standalone Python standard-library helper. Root `VERSION` is the sole project version source.

## Compatibility and limits

Python 3.11+ remains required. Historical transactions need their preserved original checkout/pin; no migration or automatic repair is supplied. Historical release notes and archived evidence remain unchanged. Verification is local only, not a live publication or deployment attestation. The previously recorded post-promotion alias-reversion and config-local Buildx plugin-discovery warnings remain unresolved; removing legacy support does not fix them.
