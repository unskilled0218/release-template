## Fixes

Package-link attempts now retain one recorded authority snapshot and check expiry after blocking validation and persistence, immediately before dispatch. Pending release tags can recover their exact approved object after Git pruning without rebuilding or changing publication identity. Historical project notes are read from their captured commit independently of the current checkout layout.

## Compatibility

Existing source/configuration/template pin checks and ownership/deletion gates remain unchanged. Keep old transactions on their original pin; this update does not migrate their checkpoints or rewrite published history. Operator-established package-writer exclusion must still cover requests in flight. This patch has local regression verification only, not a new live deployment or deletion attestation.
