## Command

```text
shorten image tag
  - latest
  - version
    - ex) 1.2.3
```

## Goal

Publish each release image with two tags: `latest` and the plain release version, such as `1.2.3`.

## Suggestions

Keep each version tag fixed so users can pull that release after `latest` moves on.
